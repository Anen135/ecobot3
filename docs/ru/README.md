# ecobot3 — Внутренняя документация

Внутренняя документация для **ecobot3** — 2D-движка/песочницы на Python и Pygame.
Документы предназначены для разработчиков проекта: они описывают архитектуру,
модули, конфигурацию и планы развития.

---

## О проекте

ecobot3 — это эксперимент по реализации минималистичного 2D-движка с расширяемой архитектурой:

* **Мир (World)** — коллекция сущностей (`Entity`) с поддержкой трёх типов миров: `bounded` (с границами), `infinite` (без границ) и `torus` (с зацикливанием).
* **Сущности** — базовый класс `Entity` плюс готовые типы: `Agent`, `Food`, `Obstacle`. Новые типы регистрируются в `ENTITY_REGISTRY` и могут загружаться из JSON-конфигурации.
* **Контроллеры** — подключаемое управление сущностями: клавиатура (WASD), мышь, ИИ (движение к еде), повороты (Q/E + W/S).
* **Камера** — режимы `follow_agent`, `follow_food` и `fixed`, с ограничением по границам для миров `bounded`.
* **Конфигурация** — все настройки хранятся в JSON-файлах в папке `config/` и загружаются через `engine.settings`.

> Тексты в коде (комментарии, docstring, сообщения коммитов) написаны на русском;
> эта документация ведётся на английском.

## Структура репозитория

```
ecobot3/
├── main.py                  # Точка входа и главный игровой цикл
├── pyproject.toml           # Настройки инструментов (ruff)
├── TODO.md                  # Техническое задание / дорожная карта
├── config/                  # JSON-конфигурация движка
│   ├── engine_config.json   #   главный конфиг (system + именованные привязки файлов)
│   ├── window_config.json   #   настройки окна
│   ├── world_config.json    #   настройки мира
│   ├── camera_config.json   #   настройки камеры
│   ├── visual_config.json   #   настройки визуализации
│   └── world_objects.json   #   объекты, загружаемые в мир
├── engine/                  # Пакет движка
│   ├── __init__.py
│   ├── settings.py          #   загрузка и экспорт конфигурации
│   ├── world.py             #   класс World
│   ├── entity.py            #   Entity, Food, Obstacle, Agent, реестр, загрузка из JSON
│   ├── control.py           #   контроллеры
│   ├── camera.py            #   класс Camera
│   ├── ui.py                #   отладочная панель и сетка
│   └── utils.py             #   Timer, StepCounter
└── docs/                    # Внутренняя документация (эта папка)
```
